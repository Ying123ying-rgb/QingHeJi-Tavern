# 酒馆人生模拟器 · QingHeJi-Tavern

**v0.3.0：玩家物资、NPC 资料解锁与副 API 语义发现。** 每个聊天拥有独立存档；核心以通用地点、行动、资源、服务和事实工作，具体世界内容来自模板、聊天或手动输入。

## 使用

在 SillyTavern 扩展管理中安装本仓库，更新后刷新浏览器。开启插件总开关和当前聊天游戏模式，点击聊天页右侧「人生」。无需构建或额外 Node 依赖。

- **状态**：世界、日期时间、所在地、货币与 stats，以及当前地点已解锁的「当前可做」。行动目前仅展示提示，无正式结算。
- **物资**：当前聊天玩家库存，支持分类、详情、来源、手动添加和修改数量。数量不明确时显示「数量未知」，不猜成 1。
- **地点**：已发现地点、逐步增加的功能/资源/服务、关联行动和手动纠错。
- **人物**：当前聊天真正遇见或认识的 NPC，纵向图鉴与逐步解锁资料。不列出 User，不自动加入当前角色卡标题；旧 actors 保留在存档中。
- **设置**：世界模板、全部行动与增删、发现记录、待确认发现、聊天历史同步和副 API 渠道。

面板直接挂载 document.body，使用底部 Sheet、五项导航和响应式网格。总开关或游戏模式关闭时隐藏入口；切聊天、刷新、局部 DOM 重建均由统一生命周期处理。

## 副 API 与历史补录

在「设置 → 副 API」添加渠道，填写地址、密钥和模型，启用并保存为当前渠道。默认温度 0.1、最大 token 2048、超时 60 秒、思考强度 none。测试连接是一次明确的独立请求。

启用后，每轮完整聊天结束读取该轮 User 与 Assistant，一轮最多扫描一次。普通游戏按钮不调用 AI。未配置或未启用渠道时使用保守本地规则，仍可手动添加地点、物资、NPC 和行动。

中途安装可用「同步当前聊天」选择最近 10 / 30（默认）/ 50 条或全部消息，按完整轮次依次扫描。已处理且未变更的消息跳过；重复同步不重复增加物资。「重新分析但不重复应用」仅生成待确认记录，可忽略或通过对应手动工具纠错。本版不提供候选批量确认执行。

副 API 采用浏览器直接请求 OpenAI Compatible `chat/completions`。服务需要允许 SillyTavern 页面的跨域请求；HTTPS 页面应使用 HTTPS API。密钥保存在宿主扩展设置，输入框遮蔽显示，不写日志或聊天存档；扩展设置不是加密密钥保险库。仅已选择且启用的渠道会接收扫描范围内聊天及必要世界上下文。

完整字段、校验、证据、去重及限制见 [v0.3.0 语义发现说明](docs/semantic-discovery.md)。旧地点与行动协议见 [v0.2.0 世界发现说明](docs/discovery.md)，其旧 UI 和「不调用副 API」描述已由本版替代。

## 数据兼容

保留 world、locations、actions、actors、controlMode、calendar、discoveryLog；新增聊天根级 inventory、npcs、processedMessageIds、pendingDiscoveries 和内部 semanticEvents。新聊天这些集合为空，不从其他聊天或角色卡复制 NPC。

玩家物资与 NPC 知识分开保存。旧 actor 内库存仍保留，不自动推定为玩家已拥有的物资。迁移及手动修改使用宿主聊天元数据保存，失败回滚；宿主未抛出的落盘失败仍需刷新实机确认。

本地行动指令仍可使用 `/life action add 名称`、`/life action remove 名称`、`/life action list`，不会发送角色消息。

## 验证与发布

```powershell
node scripts/check.cjs
node scripts/browser-check.cjs
```

第一项包含核心、旧世界/actor/action、语义与模拟宿主测试。第二项使用本机 Chrome/Edge 测试 320×740、320×400、桌面、刷新和模拟 API；可用 QHJT_CHROME 指定浏览器。测试不请求真实模型，不等同于 Android 实机验收。

Android 重点检查：仅 User 提及已到达地点、开局清点与未知数量、重复同步、NPC 渐进资料、不显示世界卡/User、渠道连接及跨域、切聊天取消扫描、刷新保存、窄屏和软键盘。

本版不开发商店、摆摊结算、种田、战斗或最终美术。完成提交后在普通 PowerShell 手动推送：

```powershell
git push origin main
```
